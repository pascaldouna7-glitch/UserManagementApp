# Java User Management App

## 📌 Description

A desktop application built with Java Swing that allows users to register, login, and manage users.

## 🚀 Features

* Login & Registration
* Password Hashing (SHA-256)
* View Users
* Delete Users
* File Storage

## 🛠️ Technologies

* Java (JDK 21)
* Swing GUI
* File Handling
* GitHub
